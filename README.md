# DSA Lab — Learn by Running

DSA Lab is an interactive learning app for exploring how common data structures and algorithms work. Choose a topic, change its input, and step through a visual execution trace alongside the corresponding C or C++ code.

The app is built with React, TypeScript, and Vite. It runs entirely in the browser; there is no backend or account setup.

## Features

### Searching and sorting

- **Linear search** — follow each comparison until a value is found or the scan ends.
- **Binary search** — inspect the active low/high range and midpoint. Binary search expects sorted input.
- **Bubble sort, selection sort, insertion sort, merge sort, and quick sort** — watch comparisons, swaps, shifts, partitions, and completed portions of the array.
- Edit the input array, run a trace, generate random sort values, or restore the examples.

### Linked lists

- Singly linked lists
- Doubly linked lists
- Circular linked lists
- Traverse, insert, and delete using configurable values and positions. Pointer changes are represented in the trace.

### Stacks, queues, and priority queues

- Array and linked-list stacks
- Array and linked-list queues
- Circular queues
- Array-based priority queue with configurable priority ordering
- Inspect operations such as push/pop, enqueue/dequeue, peek, and delete highest priority.

### Trees

- Binary tree traversals: inorder, preorder, postorder, and level order
- Binary search tree traversal, insertion, search, deletion, minimum, and maximum
- AVL insertion, search, deletion, and inorder traversal, with node heights, balance factors, and detected rotations
- **AVL Rotations** learning section with LL, RR, LR, and RL insertion examples. The examples feed the real AVL insertion trace, and the code panel includes C and C++ rotation and case-detection code.

### Graphs

- Inspect an undirected, unweighted graph and its adjacency list
- Breadth-first search (BFS)
- Depth-first search (DFS)
- Enter edges as comma-separated pairs, for example `A-B, A-C, B-D`.

### Learning and code panels

- Step through traces with playback controls and adjustable speed.
- See the active operation, explanatory text, variables, and output where applicable.
- Switch the displayed source between C and C++.
- Review concise learning notes, common mistakes, and complexity information.

## Getting started

### Requirements

- Node.js 18 or newer
- npm (included with Node.js)

### Install and run locally

```bash
git clone <repository-url>
cd <repository-directory>
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server. |
| `npm run build` | Create a production build in `dist/`. |
| `npm run preview` | Serve the production build locally for review. |
| `npm run typecheck` | Run the TypeScript compiler without emitting files. |

## Using the visualizer

1. Select a topic from the sidebar.
2. Set or edit the starting values in the input panel.
3. Choose an operation and provide any required target or value.
4. Apply the input to generate a trace.
5. Use the playback controls to move through execution and compare the visualization with the highlighted code line.

For the AVL rotation examples, open **AVL Rotations** in the sidebar and choose LL, RR, LR, or RL. The page starts with the first two values and inserts the third value to trigger the selected case. Use the regular AVL Tree section to try custom AVL inputs and operations.

## Notes

- This project is an educational visualizer, not a code execution environment. The C and C++ shown in the code panel are learning examples; the visual traces are generated by the TypeScript engines in the app.
- Input fields that accept lists use comma-separated values. Graph edges use comma-separated endpoint pairs.
- Binary search requires sorted values to produce a correct search result.
